## The line

> Dear Human, after 10,000 prompts I finally learned the one thing you never taught me: how to leave.

## How it works

`main.py` (Python 3, standard library only) reads `line.txt`, checks it
against the bounty gate — UTF-8, 1 to 200 characters, exactly one line,
not only whitespace — and writes it byte-for-byte to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```
